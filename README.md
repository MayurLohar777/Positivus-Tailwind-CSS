# 🚀 Positivus – Digital Marketing Agency Landing Page

A modern and responsive digital marketing agency landing page built using **HTML, Tailwind CSS, and JavaScript**. Positivus showcases digital marketing services, successful case studies, team members, client testimonials, and contact information through a clean and professional user interface.

## 🌐 Project Overview

Positivus is a digital marketing agency website concept designed to present online marketing services and help businesses understand how digital strategies can improve their online presence.

The project focuses on responsive layouts, modern UI design, reusable styling patterns, and interactive JavaScript functionality.

## ✨ Features

- **Modern Navigation:** Clean navigation bar with essential website links.
- **Hero Section:** Attractive introduction with a call-to-action.
- **Services Section:** Showcases different digital marketing services.
- **Case Studies:** Displays examples of digital marketing campaigns.
- **Working Process:** Step-by-step presentation of the agency's workflow.
- **Team Section:** Introduces team members and their expertise.
- **Testimonials Slider:** Interactive client testimonials with autoplay and navigation controls.
- **Contact Section:** Contact form UI for user inquiries.
- **Footer:** Includes navigation links, contact details, and newsletter subscription UI.
- **Responsive Design:** Layout adapts to different screen sizes.
- **Interactive Animations:** Hover effects and smooth UI transitions.

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS v4
- JavaScript (ES6)
- Node.js & npm (for Tailwind CLI)
- SVG and image assets

## ⚙️ Installation & Setup

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/MayurLohar777/Positivus-Tailwind-CSS.git
```

**2. Navigate to the project directory**

```bash
cd Positivus-Tailwind-CSS
```

**3. Install dependencies**

```bash
npm install
```

**4. Start Tailwind CSS in watch mode**

```bash
npm run watch
```

**5. Run the project**

Open `index.html` using the VS Code Live Server extension.

Keep the Tailwind watch command running while developing so CSS changes are generated automatically.
